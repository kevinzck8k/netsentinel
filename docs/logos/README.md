# Logo sources

`make_architecture.py` inlines these marks into the figure as base64 vectors, so
the diagram renders without fetching anything at view time.

| File | Source | Licence |
|---|---|---|
| `redis.svg`, `docker.svg`, `python.svg`, `opentelemetry.svg`, `sqlite.svg`, `pydantic.svg` | [simple-icons](https://github.com/simple-icons/simple-icons) | CC0-1.0 |
| `qdrant.svg` | [Qdrant brand resources](https://qdrant.tech/) | Brand asset |
| `deepseek.svg`, `langchain_color.svg` | [svgl](https://svgl.app/) | Brand asset |

The simple-icons marks ship monochrome; the generator applies each project's
brand colour at build time rather than storing a recoloured copy.

Every logo is a trademark of its owner and appears here only to identify the
component it labels. Their inclusion implies no endorsement of this project.
